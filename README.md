# BinFit Lab

Browser-local Gridfinity tools at https://binfitlab.com. Application source and validation evidence will be added with the tested beta release.

The engine build captures the actual OpenSCAD source, submodules, dependency sources, patches and build recipe before compiling a browser engine. It does not claim that the legacy prebuilt engine has been independently reconstructed.

Application code: GPL-3.0-only. OpenSCAD and its dependencies retain their upstream licenses. Physical fit testing remains pending.
